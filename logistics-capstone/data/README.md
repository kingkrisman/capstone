# Data

Place the raw CSV files from the Logistics Operations Database here before running `analysis/analysis.py`:

- customers.csv
- delivery_events.csv
- driver_monthly_metrics.csv
- drivers.csv
- facilities.csv
- fuel_purchases.csv
- loads.csv
- maintenance_records.csv
- routes.csv
- safety_incidents.csv
- trailers.csv
- trips.csv
- truck_utilization_metrics.csv
- trucks.csv

The raw files are not committed to this repository (about 60MB, and provided as course material). The dashboard and PDF don't need them, because the computed metrics are stored in `analysis/output/data.json`.
